# README generator rules

- Persistent profile content belongs in `templates/README.md.tpl`; `README.md` is generated by `.github/workflows/readme-scribe.yml`.
- Preserve the `{{range ...}}` and `{{- end}}` readme-scribe directives in the template.
- The workflow passes `templates/README.md.tpl` as `template` and `README.md` as `writeTo`; keep those paths aligned when editing the workflow.
- The workflow commits to `main` with `GITHUB_TOKEN`; treat `PERSONAL_GITHUB_TOKEN`, `GITHUB_TOKEN`, and the branch as protected workflow inputs.
