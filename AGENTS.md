# Agent instructions

`AGENTS.md` is the canonical project instruction file. `CLAUDE.md`, `GEMINI.md`,
and `.github/copilot-instructions.md` are synchronized mirrors.

## Project

GitHub profile repository for `pwnyprod` / Jonas Hoppe.

- `README.md` is generated from `templates/README.md.tpl`.
- `.github/workflows/readme-scribe.yml` regenerates the README on every push and
  on an hourly schedule.
- The workflow uses `muesli/readme-scribe` and commits the generated README to
  the `main` branch.
- There is no application source code or local dependency/toolchain setup.

## Workflow and files

- Edit `templates/README.md.tpl` for persistent README changes.
- Do not hand-edit `README.md`; it is generated by the GitHub Actions workflow.
- Keep the template's `readme-scribe` directives intact when changing its
  layout or sections.
- `.github/workflows/readme-scribe.yml` is the only project workflow.
- `.gitignore` excludes IntelliJ project files and generated IDE output.

## Validation

No project-specific build, test, lint, or formatter command is configured.

- Check whitespace and patch errors with `git diff --check`.
- For workflow changes, inspect the complete workflow and its referenced
  template before committing; GitHub Actions execution is the authoritative
  validation.

## Conventions

- Keep generated content in `README.md` and source content in
  `templates/README.md.tpl`.
- Preserve the existing GitHub profile links, template directives, and section
  order unless the task explicitly changes them.
- Keep changes focused on the requested README or workflow behavior.

## Security and constraints

- Never commit, print, or copy GitHub tokens or other secrets. The workflow
  receives `PERSONAL_GITHUB_TOKEN` and `GITHUB_TOKEN` through Actions secrets.
- Do not modify generated `README.md` as a substitute for changing the template.
- Do not change the workflow's target branch, permissions, or secret names
  without verifying the required GitHub Actions behavior.
- Do not modify `.idea/`, `out/`, `gen/`, or other generated IDE files.
- Do not change unrelated profile content or linked repositories while working
  on the README generator.

## Commits and pull requests

- Do not create commits or push changes unless explicitly requested.
- Summarize template/workflow changes and validation in the pull request.
